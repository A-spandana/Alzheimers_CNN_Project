# Dataset Information

This project uses the Alzheimer MRI Dataset obtained from Kaggle.

**Dataset source:** https://www.kaggle.com/datasets/azminur2856/alzheimer-mri-dataset

The dataset contains MRI images classified into four categories:

- NonDemented
- VeryMildDemented
- MildDemented
- ModerateDemented

The images are loaded and preprocessed in the project notebook.

**Note:** The dataset files are not included in this repository. Please obtain them from the original source and follow the dataset's license and terms of use.
